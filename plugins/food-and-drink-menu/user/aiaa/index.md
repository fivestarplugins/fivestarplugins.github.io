We've recently made use of the AIT [AI Admin Assistance WordPress plugin](https://www.wpaiplugins.dev/wordpress-ai-admin-assistance/) to add help and guidance directly in the plugin admin for Five Star Restaurant Menu.

Using this tool, **we have added guidance, links to documentation and other help content to each page in the plugin admin** (such as the menu and menu item create/edit pages or the settings pages).

The AI Admin Assistance tool also comes with a **built-in AI Assistant that uses the information present on the page to dynamically answer any question you ask it in real time**.

No more getting stuck and no more waiting for help. Instead of sifting through documentation or waiting for a reply from support, get the answers you need for any issues you are facing in configuring or using the plugin right there in the plugin admin.

This is useful whether you are a developer or the end user yourself. 

**As a developer**, you can make sure to configure this before handing off the site to your user, to ensure they have a first recourse for any help they need in using the menu and ordering system. 

**As an end user**, you can install this to speed up your learning curve and ensure that you never get stuck if you happen to run into any issues while configuring or using the restaurant menu plugin.

Please visit the following pages to learn more about installing and configuring the admin assistance plugin as well as accessing and using the included help, guidance and AI assistant.

- [Accessing and using the built-in help and guidance](use)

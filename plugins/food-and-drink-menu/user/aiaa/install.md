Accessing the in-admin help is quick and easy. Just install the AIT AI Admin Assistance plugin.

You can find this free plugin here:

[https://wordpress.org/plugins/ait-ai-admin-assistance/](https://wordpress.org/plugins/ait-ai-admin-assistance/)

Or search for it directly in your WordPress admin.

**To install the plugin:**

1. Go to the **Plugins** page in your WordPress admin area.
2. Click the **Add Plugin** button at the top of the page.
3. In the search bar on the right, enter **AIT AI Admin Assistance** and hit enter/return.
4. Find the **AIT AI Admin Assistance** plugin in the list (it should be the first result), click the **Install Now** button, and follow the instructions.
5. Once installed, click the **Activate Now** link. If you don’t see that link, you can go to your **Plugins** list at any time and activate it from there.

## (No) Configuration

There is nothing to configure with the AIT AI Admin Assistance plugin. We've coded all the help into the restaurant menu plugin using the filters and actions that the AIT AI Admin Assistance offers. So, **as soon as you activate the AIT AI Admin Assistance plugin, all the in-admin help and the AI assistant for the Five Star Restaurant Menu plugin will be available**!

You are now ready to start [accessing the included help](use) and [AI assistant](ai-assistant).
